# Unity-Dark-Fantasy-Platformer
A 2D dark fantasy platformer developed in Unity using C# for A-Level Computer Science coursework.
The game is a 2D side-scrolling dark fantasy platformer including:
1. Character movement and animations
2. Health and stamina systems
3. Interactive NPC
4. Enemy AI
5. Upgrade system
6. Multiple scenes/ areas
7. Various UI implementations

Scored 60/70 marks 
Supported by 143-page technical report - ~19500 words
